## 环境与运行

本次已建立项目专用 `.venv`，使用系统已有NumPy、SciPy、Matplotlib，并在该环境安装openpyxl。其他Python 3.10及以上环境可按requirements.txt安装。

```powershell
python -m pip install -r requirements.txt
python run.py all
python run.py experiments
python run.py validate
python -m unittest discover -s tests -v
```

在当前Windows环境中，将上述 `python` 替换为 `.\.venv\Scripts\python.exe` 即可使用已配置的环境。

```powershell
python run.py q1
python run.py q2
python run.py q3
python run.py baseline --question 2
python run.py baseline --question 3
python run.py q2 --config output/experiments/q2_selection.json
python run.py q3 --config output/experiments/q3_selection.json
```

`all` 重算第二/三问并审计，不重写第一问；`q1` 显式调用原第一问算法。`all --experiments` 进一步执行35项消融。`baseline` 只复现并比对旧费用。`validate` 从轨迹和工作簿独立核算，更新validation.json。q2/q3默认重做1月选参，`--config` 可直接复现已选配置；支持 `--output-dir`，输入支持 `--attachment-dir`。

原先分散的run_q2_causal.py、run_q2_legacy.py、q3_model.py等入口已合并进run.py，不再保留重复入口。

## 三问数学模型和求解方法

完整的变量、假设、约束、预测公式、求解步骤及表格对应见 [当前数学模型](docs/current_models.md)。改进前的逐问推导保留在 [历史建模审查](docs/model_review.md)，该快照中的旧路径和“拟议”状态不代表当前实现。

三问共用十分钟供需平衡和储能递推，电量单位为kWh：

$$
g_t+V_t+r_t+e_t=L_t+c_t+s_t,\qquad
E_t=E_{t-1}+0.9c_t-r_t/0.9.
$$

储电量1200—10800 kWh，充放电每段上限5000/6 kWh。输入功率乘1/6转换成电量；电量变量不能再重复乘时长。第一问无紧急购电，第二/三问在实际运行时补足剩余缺口。

| 问题 | 当前模型 | 分析与求解方法 |
|---|---|---|
| 第一问 | 确定性单日LP；首尾6000 kWh；最小化正常购电费 | 给定负荷/光伏，联合优化购电和储能，HiGHS求解并检查平衡；原代码与时间标签保持不变 |
| 第二问 | 5场景LP；共享购电/储能计划；显式期望紧急费用 | 因果自适应预测、历史整条净负荷误差场景；0点固定当天正常购电；实际储能逐段反馈，状态跨日传递 |
| 第三问 | 自适应预测、净负荷0.65分位裕度、24小时MPC | 0/6/12/18点重算，执行随后6小时；加入相对0点计划的调整费；十分钟储能反馈 |

第一问目标 $C_1=\sum p_tg_t$，并要求 $E_0=E_{144}=6000$；第二问实际评价为 $C_2=\sum(p_tg_t+5p_te_t)$。第三问实际评价为：

$$
C_3=\sum_{d,t}\left[p_tg^{\mathrm{fin}}_{d,t}
+0.5p_t|g^{\mathrm{fin}}_{d,t}-g^0_{d,t}|+5p_te_{d,t}\right].
$$

取消部分不重复支付原计划全价。“调整购电量”表填最终正常购电总量，该表费用含正常费和调整费、不含紧急费，不能再加一次“计划购电量”表的费用。

## 具体改进了什么

| 原方案 | 已实施内容 | 使用状态 |
|---|---|---|
| P0-1 时间映射 | 第二/三问统一采样端点、午夜与4小时块，改输出标签而不平移数值；检测错序/重复时标 | 第二/三问启用，第一问暂缓 |
| P0-2 计费追溯 | 统一正常、增购、减购、紧急费用；完整计划快照和逐段执行；逐次收费另列敏感性统计 | 启用 |
| P1-1 预测 | 昨日、上周、七日加权、日历岭回归；以前21个完整日误差自适应选择；跨日按目标日预测 | 启用 |
| P1-2 裕度 | 净负荷联合误差、滚动窗口及时间衰减 | 第三问主模型使用；第二问使用整条误差场景 |
| P1-3 场景/CVaR | 共享计划确保非预见性，显式期望紧急费，另实现尾部紧急费CVaR | 第二问使用场景，CVaR保留对照 |
| P1-4 备用 | 柔性期末备用目标、两种比例候选；费用平局优先简单模型 | 已验证，当前弱惩罚未显示有效收益，主模型不启用 |
| P1-5 更新价值 | 全部8种时刻组合，连续热身/共同初值两套比较；光伏与负荷修正四组合；事件触发 | 对照已实现，主模型使用四个规定时刻 |
| P2-1 互斥/物理 | 主目标最优后在百万分之一元容差内最小化吞吐量，检查计划和实际重叠 | 第二/三问启用；未触发MILP条件，未虚构退化成本 |
| P2-2 效率/验证 | 复用稀疏矩阵和预测缓存；输入/代码哈希；独立核算与未来数据扰动测试 | 启用 |
| P2-3 论文表 | 自动生成四个指定日期表1—3，紧急区间按每段电价计费 | 第二/三问启用；第一问暂缓 |

场景LP的共享储能计划是保守近似，实际反馈与计划损失仍有差别；经验分位数不是全天可靠率证明。备用、CVaR和事件触发均保留实验配置，不把“已经编码”当成“已证实节费”。
