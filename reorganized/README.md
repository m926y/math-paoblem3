# C题问题1、问题2整理版

本目录是对原 `chat.md` 与 `main.py` 的核对和重构版本。原文件保留不覆盖。

## 已确认的数据对应关系

- `../附件1.xlsx`：问题1的一天数据，包含电价、负荷功率和光伏预测功率；问题2只使用其中的电价列。
- `../附件2.xlsx`：2025 年 365 天、每天 144 个十分钟点的负荷实际功率和光伏实际功率。问题2的预测只使用这两个工作表的历史实际值，不使用附件1中的负荷和光伏列。
- `../附件5/result1.xlsx`、`result2.xlsx`：输出模板。

## 对原模型和代码的主要判断

1. 问题1的能量平衡、储能递推、充放电功率上限、SOC上下限和日终等于日初等约束基本正确，十分钟功率转电量 `kW / 6 = kWh` 也正确。原程序的问题是输出没有严格按附件5模板组织，且没有对求解状态、数值平衡和边界做检查。
2. 问题2原代码不正确。它把计划购电、充放电和SOC同时放进“预测平衡”和“实际平衡”，等价于要求同一套动作同时满足两套数据；同时没有弃电变量，实际光伏高于预测时可能不可行。
3. 原代码的预测误差计算错误：`load[day-1] - load_pred` 比较的是前一天实际值和当天预测值；前面的 `for i in range(day)` 循环计算结果也没有使用。
4. 原代码从数组第 8 天开始输出，且用 `day+1` 代替日期，和模板要求的 2025-02-01 至 2025-12-31 不一致。
5. 原代码在求解时直接把当天实际负荷、实际光伏放进模型，因此发生了未来信息泄漏。整理版先用历史数据形成日前计划，再用当天实际值只做运行仿真和紧急购电核算。

## 整理版的建模约定

时间点记为 `t=1,...,144`，`dt=1/6 h`。功率先转换为电量。储能效率 `eta=0.9`，容量范围 `[1200,10800] kWh`，单个十分钟充放电量上限 `5000/6 kWh`。

### 统一符号、单位和参数

令 `t=1,...,T` 为十分钟时段，`T=144`，`d=1,...,365` 为 2025 年日期索引。功率用 kW，时段电量用 kWh，电价用 CNY/kWh。十分钟长度为：

`Delta t = 10/60 = 1/6 h`

因此附件中的功率转换为电量：

`load_(d,t) = LoadPower_(d,t) * Delta t`

`pv_(d,t) = PVPower_(d,t) * Delta t`

储能参数为：

| 参数 | 符号 | 数值 |
|---|---:|---:|
| 储能初始电量 | `E_0` | 6000 kWh |
| 储能容量 | `E_max` | 12000 kWh |
| SOC下限 | `E_min` | 1200 kWh |
| SOC上限 | `E_bar` | 10800 kWh |
| 充放电功率上限 | `P_max` | 5000 kW |
| 单个十分钟最大充放电量 | `Q_max=P_max*Delta t` | 833.3333 kWh |
| 充放电效率 | `eta` | 0.9 |

其中 `g_t` 为正常购电量，`c_t` 为充电量，`r_t` 为放电量，`E_t` 为时段末储能量，`s_t` 为弃电量。题目没有给出上网电价，因此光伏过剩只能弃电，且 `s_t` 必须允许非负。

### 问题1：确定性单日储能调度

附件1给出一天的电价、负荷功率和光伏预测功率。决策变量为：

`g_t >= 0, c_t >= 0, r_t >= 0, s_t >= 0`

`E_min <= E_t <= E_bar,  t=0,...,T`

目标函数是最小化全天正常购电费用：

`min C_1 = sum_(t=1)^T p_t*g_t`

能量平衡约束为：

`g_t + pv_t + r_t = load_t + c_t + s_t,  t=1,...,T`

储能递推约束为：

`E_t = E_(t-1) + eta*c_t - r_t/eta,  t=1,...,T`

初末状态约束为：

`E_0=6000,  E_T=6000`

充放电量上限为：

`0 <= c_t <= Q_max,  0 <= r_t <= Q_max`

在本题电价为正、没有售电收益的前提下，线性规划不会因为同时充放电而获得收益，程序会额外检查 `min(c_t,r_t)` 是否接近 0。如果要在含负电价或允许售电的扩展问题中严格禁止同时充放电，应增加二进制变量 `u_t`：

`c_t <= Q_max*u_t,  r_t <= Q_max*(1-u_t),  u_t in {0,1}`

### 问题2：日前计划、滚动再调度与实际运行仿真

问题2的关键是区分“0:00制定的计划”和“当天实际运行”。输出日期是 2025-02-01 至 2025-12-31，共 334 天。2025 年 1 月不计入问题2的输出费用，但不再只是预测历史：程序先用 1 月实际负荷、实际光伏和电价逐日作出储能决策，并把储能状态传递到 2 月。

#### 0. 用 1 月实际数据确定 2 月初始储电量，并修正月末边界效应

设 1 月 1 日开始时储电量为题目给定的 `6000 kWh`。对 1 月每一天 `d=1,...,31`，使用当天实际数据求解与问题1相同的日前线性规划。为避免最后一天无约束放电到下限，程序根据下一日的安全预测设置跨日储能保留目标。

`(g^Jan_d,c^Jan_d,r^Jan_d,E^Jan_d) = argmin C^Jan_d`

其中负荷和光伏输入分别为附件2中的 `L^act_d` 和 `V^act_d`，且满足：

`E^Jan_{d,0}=E^Jan_{d-1,T}`，`E^Jan_{1,0}=6000`

`E_min <= E^Jan_{d,t} <= E_bar`

令下一日高价时段集合为 `H`，下一日安全预测的净负荷为：

`N_{d+1,t}=max(L^safe_{d+1,t}-V^safe_{d+1,t},0)`

跨日储能目标为：

`E^tar_d=clip(E_min+0.20*sum_(t in H) N_{d+1,t}*Delta t,E_min,E_bar)`

其中 `H` 为电价不低于 75% 分位数的时段，`0.20` 为风险储备比例。每天增加终端约束 `E^Jan_{d,T}=E^tar_d`，因此目标由实际数据和下一日风险预测共同决定，不是简单固定为 6000 kWh。

当天决策结束后，将 `E^Jan_{d,T}` 作为下一天的初始储电量。因此 2 月 1 日的初始值由以下递推得到：

`E^Feb_{1,0}=E^Jan_{31,T}=5869.3479611 kWh`

代码中该值记录在 `output/q2/check.txt` 的 `february_initial_soc` 字段，并另存了 1 月状态传递过程 `output/q2/january_warmup.csv`。1 月的调度费用只用于初始化过程记录，不计入下面 334 天的问题2总费用。

#### 1. 七日加权预测

对目标日 `d` 的每个时段 `t`，分别对负荷和光伏实际功率进行预测：

`hat L_(d,t) = sum_(i=1)^7 w_i L_(d-i,t)`

`hat V_(d,t) = sum_(i=1)^7 w_i V_(d-i,t)`

权重为：

`(w_1,...,w_7)=(0.40,0.25,0.15,0.10,0.05,0.03,0.02)`，且 `sum_i w_i=1`。

这里的 `L` 和 `V` 均来自附件2，附件1中的负荷和光伏列不参与问题2预测。

#### 2. 80%分位安全裕度

对每一个历史目标日 `j`，用当时可获得的前 7 天数据生成滚动预测，并形成不利误差：

`e^L_(j,t) = max(L_(j,t)-hat L_(j,t),0)`

`e^V_(j,t) = max(hat V_(j,t)-V_(j,t),0)`

截至目标日 `d`，以历史误差样本的 80% 分位数作为安全裕度：

`m^L_(d,t) = Quantile_0.8({e^L_(j,t): 7<=j<d})`

`m^V_(d,t) = Quantile_0.8({e^V_(j,t): 7<=j<d})`

形成日前调度输入：

`L^safe_(d,t) = max(hat L_(d,t)+m^L_(d,t),0)`

`V^safe_(d,t) = max(hat V_(d,t)-m^V_(d,t),0)`

这样负荷采用偏大的安全输入，光伏采用偏小的安全输入，且误差计算没有使用目标日实际值。

#### 3. 日前计划优化

问题2计划阶段使用附件1的 144 个电价点，并把它们作为每天相同的电价曲线。对每个目标日求解：

`min C_d^plan = sum_(t=1)^T p_t*g^plan_(d,t)`

约束为：

`g^plan_(d,t)+V^safe_(d,t)+r^plan_(d,t)`

`= L^safe_(d,t)+c^plan_(d,t)+s^plan_(d,t)`

`E^plan_(d,t)=E^plan_(d,t-1)+eta*c^plan_(d,t)-r^plan_(d,t)/eta`

`E_min <= E^plan_(d,t) <= E_bar`

`0 <= c^plan_(d,t),r^plan_(d,t) <= Q_max`

`E^plan_(d,0)=E^plan_(d-1,T)`，第一天取由 1 月实际数据决策得到的 `E^plan_(2025-02-01,0)=E^Feb_{1,0}`。

问题2没有强加每日 `E_T=E_0`。日前计划的日终SOC作为计划状态，但实际运行后以实际SOC闭环传递到下一日。

#### 4. 实际运行、闭环SOC和有限再调度

在实际运行阶段，正常购电量 `g^plan` 仍按照日前计划执行，但充放电允许根据当前实际偏差进行有限再调度。若实际负荷偏大或实际光伏偏小，先取消相反方向的计划充电，再利用剩余放电能力；若实际负荷偏小或实际光伏偏大，则先取消相反方向的计划放电，再利用剩余充电能力。只有储能调节能力不足时才产生紧急购电或弃电。

实际运行平衡为：

`g^plan_(d,t)+V^act_(d,t)+r^act_(d,t)+e_(d,t)`

`=L^act_(d,t)+c^act_(d,t)+s^real_(d,t)`

实际储能状态闭环更新：

`E^act_(d,t)=E^act_(d,t-1)+eta*c^act_(d,t)-r^act_(d,t)/eta`

并使用：

`E^plan_(d+1,0)=E^act_(d,T)`

当天实际净缺口为：

`q_(d,t)=L^act_(d,t)+c^act_(d,t)-V^act_(d,t)-r^act_(d,t)-g^plan_(d,t)`

紧急购电量和实际弃电量分别为：

`e_(d,t)=max(q_(d,t),0)`

`s^real_(d,t)=max(-q_(d,t),0)`

紧急购电价格为当时正常电价的 5 倍，所以当天实际总费用为：

`C_d = sum_t p_t*g^plan_(d,t) + 5*sum_t p_t*e_(d,t)`

全年输出期总费用为：

`C_2 = sum_(d=2025-02-01)^(2025-12-31) C_d`

这里采用“日前正常购电计划固定、储能进行有限再调度、剩余缺口用紧急购电补足、剩余过剩弃电”的约定。实际数据只用于当天运行修正和评价，不进入当天日前预测与日前优化，避免未来信息泄漏。

## 运行

在本目录运行：

```bash
python run_q1.py
python run_q2.py
```

依赖见 `requirements.txt`。输出在 `output/q1/` 和 `output/q2/`，包括 Excel、CSV、PNG 和检查报告。
