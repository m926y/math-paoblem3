# 第三问模型、费用口径与消融结果

## 模型与信息边界

`q3_model.py` 从1月1日起使用同一套因果滚动策略。0点形成当天初始购电计划，6点、12点、18点在附件3相应预报发布后更新尚未执行的计划。每个十分钟只读取当时已经观测到的实际负荷和光伏，用储能闭环修正供需偏差；未来实际数据不会进入当前决策。

24小时MPC由 `q3_dispatch.py` 求解。预测平衡和SOC递推为：

`g_(tau,t) + Vsafe_(tau,t) + r_(tau,t) = Lsafe_(tau,t) + c_(tau,t) + spill_(tau,t)`

`E_(tau,t) = E_(tau,t-1) + 0.9*c_(tau,t) - r_(tau,t)/0.9`

SOC范围为1200—10800 kWh，十分钟充放电量上限为833.3333 kWh。线性规划用极小循环惩罚消除无收益的同时充放电；当前全部结果的实际重叠为0，但模型没有二进制互斥变量。

负荷用历史同时间点加权预测和单侧安全裕度；6/12/18点根据最近一小时已观测误差修正未来负荷，并随预测提前量衰减。光伏使用附件3中对应发布时间的24小时预测，并用当时已经形成的历史预测误差估计0.8分位单侧安全裕度。0.8分位数是风险裕度参数，不等同于经证明的系统可靠度。

## 固定费用口径

最终结果只统计2月1日至12月31日334天。令 `g0_t` 为0点计划，`g_t` 为当天最后一次适用更新后的正常购电量，`e_t` 为紧急购电量，则：

`C3 = sum(p_t*g_t) + 0.5*sum(p_t*abs(g_t-g0_t)) + 5*sum(p_t*e_t)`

减购时，已交付正常电量按正常电价结算，取消部分另付50%调整费；不会再对取消部分重复支付完整计划价。增加和减少均按绝对差额计50%调整费。软终端价值只进入滚动优化目标，作为未来储电的机会价值，不直接计入上述实际结算费用。

## 运行

默认主版本为四次累计更新、无终端价值：

```powershell
python q3_model.py
```

默认生成 `output/q3/result3.xlsx` 和 `output/q3/summary.json`。对照实验可分别运行：

```powershell
python q3_model.py --update-hours 0
python q3_model.py --update-hours 0,6
python q3_model.py --update-hours 0,6,12
python q3_model.py --update-hours 0,6,12,18
python q3_model.py --update-hours 0,6,12,18 --terminal-value-factor 0.9
```

每个更新时间组合都是累计式：`0,6,12` 表示保留0点计划，并在6点和12点吸收新预报。

## 更新时刻消融

所有版本使用同一输入、预测参数、储能执行和费用口径，仅改变允许的计划更新时间。

| 更新时间 | 正常购电费用 | 调整费用 | 紧急购电量 | 紧急购电费用 | 总费用 |
|---|---:|---:|---:|---:|---:|
| 0点 | 16,509,341.1451 | 0.0000 | 373,115.9190 | 2,245,435.1757 | 18,754,776.3208 |
| 0、6点 | 16,141,393.7887 | 617,393.4012 | 234,504.3220 | 1,448,092.4986 | 18,206,879.6885 |
| 0、6、12点 | 15,775,513.0432 | 909,680.6882 | 164,694.8839 | 1,009,142.7282 | 17,694,336.4596 |
| 0、6、12、18点 | 15,991,923.8314 | 1,188,858.4538 | 33,494.5713 | 169,030.2381 | **17,349,812.5234** |

四次更新相对只在0点计划减少总费用1,404,963.7975元，即7.49%，并减少紧急购电339,621.3477 kWh，即91.02%。新增更新时间会增加调整费用，但本数据中紧急购电和总费用的下降更大，因此完整四次更新是当前主版本。

## 软终端价值对照

无终端价值版本的系数为0；对照版本令窗口末端每kWh储电价值为电价中位数的0.9倍，即0.726615元/kWh。两者都采用0/6/12/18点更新。

| 终端价值系数 | 2—12月总费用 | 紧急购电量 | 2月初始SOC |
|---:|---:|---:|---:|
| 0 | **17,349,812.5234元** | 33,494.5713 kWh | 9,661.9995 kWh |
| 0.9 | 17,868,920.8126元 | 31,898.8835 kWh | 10,800.0000 kWh |

软终端价值减少紧急购电1,595.6877 kWh，但总费用增加519,108.2892元，并使储能大部分时间偏向上界。它在当前权重下没有改善主评价指标，因此作为完整对照保留，不替换系数0的主版本。这个结论只适用于当前软价值形式和系数0.9，不能外推为所有终端约束都无效。

## 当前主结果与验证

四次累计更新、终端价值系数0的结果为：正常购电费用15,991,923.8314元，调整费用1,188,858.4538元，紧急购电费用169,030.2381元，总费用17,349,812.5234元，紧急购电量33,494.5713 kWh。实际SOC为1200.000001—10799.999999 kWh，最大实际能量平衡残差为4.55e-13 kWh。

`validate_project.py` 会核对result3四个官方工作表、334天日期、计划和调整表的逐日总量与费用、紧急购电汇总、SOC与平衡残差、工程基线费用及极端压力样例。第四问没有实现，也不由第三问入口读取附件4。
